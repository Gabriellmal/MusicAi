How to Use

LERC stands for Lyrics with Embedded Rhythm Codes. It's a text format that combines lyrics with rhythm notation using simple codes:

  • [Q]: Quarter note
  • [H]: Half note
  • [E]: Eighth note
  • [W]: Whole note
  • [.]: Rest

Your LERC should include:

  1. Metadata (at the top in brackets):
    • [BPM: number] - Beats per minute
    • [KEY: key] - Musical key (e.g., C major)
    • [CHORDS: chord progression] - Optional chord progression
    • [STYLE: genre] - Music style (e.g., pop, rock, jazz)
  2. Sections marked in parentheses: (Verse 1), (Chorus), etc.
  3. Lyrics with rhythm codes
